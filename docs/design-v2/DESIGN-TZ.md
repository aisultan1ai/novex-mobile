## 1. Принципы нового дизайна

1. **Белый фон, один акцент.** Фон экранов — `#FFFFFF`. Cyan `#22C9E0` — только главная кнопка (CTA),
   выбранный элемент (рамка + галочка) и точки «новое». Большие площади cyan не заливать.
2. **Navy — для веса**: активная вкладка, цены, тёмная шапка трекинга, онбординг.
3. **Стекло.** Плавающий таб-бар, нижние панели с итогом, шапки при прокрутке, кнопки поверх карты,
   нижние листы — полупрозрачные с размытием (`expo-blur`).
4. **Один шрифт — Inter.** Space Grotesk остаётся только в словесном знаке «novex».
5. **Таб-бар только с иконками**, без подписей. Подписи — в `accessibilityLabel`.
6. **Кнопки — пилюли** (полностью скруглённые). Поля ввода и карточки — скругление 12–20.
7. **Коды городов** как в авиабилетах: `ALA ┈┈→ NQZ`. Используются в маршрутах (расчёт, тарифы, заказы, трекинг).
8. **Движение только по делу** (раздел 7). Никаких постоянных фоновых анимаций, кроме иллюстраций онбординга.
9. **Без эмодзи, без стоковых картинок, без градиентов-подложек.** Иконки — `lucide-react-native`, stroke 1.75.

Макеты сделаны в светлой теме. Тёмную собрать по тем же правилам:

## 7. Анимации (Reanimated)

Все — с проверкой `useReducedMotion()` (при включённой настройке — мгновенная смена состояния).

| Где | Что | Параметры |
|---|---|---|
| Выбор карточки / чипа / размера | смена рамки и фона + появление галочки (scale 0.6→1) | 200 мс, `Easing.bezier(0.2,0.8,0.2,1)` |
| Цена в `BottomBar` | старое значение уходит вверх с fade, новое въезжает снизу (6pt) | 200 мс |
| Линия прогресса шагов | ширина от предыдущего шага к текущему при входе на экран | 500 мс |
| Кнопка «поменять города» | поворот иконки 180° | 250 мс |
| Сжатие шапки при прокрутке | большой заголовок fade-out, стеклянная шапка fade-in (по порогу) | 200 мс; можно интерполировать по `scrollY` |
| Билет → трекинг | раскрытие от рамки карточки до экрана, контент трекинга появляется с задержкой 200 мс | 450 мс |
| Шапка трекинга | прозрачная → светлое стекло, кнопки на тёмном → на светлом | 250 мс |
| Маршрут на схеме трекинга | линия «прорисовывается» один раз при открытии | 1000 мс |
| `Sheet` | выезд снизу + затемнение | 280–300 мс |
| Нажатие на кнопку | scale 0.98 | 120 мс |
| Онбординг | непрерывное движение коробки/грузовика/самолёта; смена слайда — fade + сдвиг текста 12pt | цикл 3.6 с |
| «Заказ оформлен» | галочка pop (0.4→1.1→1) один раз | 500 мс |

Haptics (`src/lib/haptics.ts`): выбор тарифа — selection, копирование — success, ошибка — error.

## 10. Доступность

- Контраст текста ≥ 4.5:1 (крупный ≥ 3:1). Cyan как цвет текста на белом **не использовать**.
- Область нажатия ≥ 44×44 (Android 48×48), включая иконки таб-бара и «копировать».
- Иконочные кнопки — `accessibilityLabel`; выбранные карточки — `accessibilityState={{ selected: true }}`; переключатели — `accessibilityRole="switch"`.
- Статус = цвет + текст. Коды городов читаются диктором как названия городов.
- «Уменьшить движение» и «Уменьшить прозрачность» — уважать (разделы 3 и 7).

## 11. Порядок работы (отдельные PR / коммиты)

1. Токены + шрифты + `expo-blur` + `GlassSurface`. Без изменений экранов. `npm run check` зелёный.

После каждого шага: `npm run check`, скриншоты iOS (iPhone 15) и Android (360×800) в светлой и тёмной теме,
ru и kk — приложить к отчёту, сравнить с макетами.

## 12. Критерии приёмки

- Экраны визуально совпадают с макетами (отступы ±2pt, цвета — точные токены, шрифт — Inter).
- Таб-бар только с иконками, плавает со стеклом на iOS; на Android — стеклянный навбар; диктор называет вкладки.
- Стекло работает на iOS и Android, с фолбэком при «уменьшить прозрачность».
- Все анимации из раздела 7 есть и отключаются при «уменьшить движение»; постоянных анимаций нет (кроме онбординга).
- Логотипы перевозчиков — настоящие; трек-номера в формате `CSE-…`; коды городов из `cityCodes`.
- ru и kk без обрезанного текста; тёмная тема без нарушения контраста.
- `npm run check` зелёный, новые компоненты покрыты тестами рендера.

## 13. Открытые вопросы (не блокируют работу)

1. **Карта и ETA курьера** — нужны координаты/ETA в API (задача бэкенду). До этого — статичная схема (6.8).
2. **Права на логотипы перевозчиков** в приложении — подтвердить у команды (на сайте они уже используются).
3. **Kaspi** — экран оплаты должен допускать третий способ оплаты (`SelectableCard`), см. продуктовое ТЗ.
4. **Казахские тексты** онбординга и новых экранов — вычитать носителем.
